Integrations & Data Connectors
This screen shows the data pipelines that feed TerraCAP automatically — so that zone authority and tenant staff spend less time entering data manually. Each connector pulls data from an external system and maps it to the correct GHG scope and category. Green = live and pulling data. Amber = partially working or needs attention. Purple = not yet connected (Phase 2). All API credentials are stored in AWS Secrets Manager (ap-south-1, Mumbai) and are never visible in the UI.
ℹ️
How data enters TerraCAP: There are three routes — (1) automatic pull via these connectors, (2) CSV upload via Zone Data Entry or individual tenant dashboards, and (3) direct manual entry in the data entry forms. Connectors are the preferred route as they eliminate manual errors. Where a connector shows an issue, the system falls back to CSV/manual and flags the gap in the bell alerts.

DISCOM / AP-TRANSCO
API pull · monthly meter readings
 Fetches kWh consumed per utility meter number from the AP electricity board. Each meter is mapped to a zone asset or tenant unit in Zone Data Entry. → Scope 2 (location-based)
Emission factor: CEA grid intensity, AP region		 ⚠ 9 / 12 meters active 22 Mar 2025
GSTN / e-Way Bill API
API pull · tenant consent required per tenant
 Pulls procurement transaction data from the GST e-Way Bill system with tenant consent. Maps goods categories to emission factors for purchased goods and services. → Scope 3 Cat 1 (purchased goods & services) per tenant Active — 10 tenants consented 31 Mar 2025
CCTS India Registry ?
How to set up: AMTZ must first register as a zone sub-registrar with BEE (Bureau of Energy Efficiency) at ccts.beeindia.gov.in. Once approved, BEE issues a sub-registrar ID and API credentials. Enter those credentials in Zone Configuration → CCTS Sub-Registrar Settings. TerraCAP then connects automatically to sync credit balances.
BEE API · AMTZ as sub-registrar
 Synchronises carbon credit project status, issuance, and retirement with BEE's central CCTS registry. AMTZ operates as zone sub-registrar — this connector keeps credit balances live. → Zone Credit Balance · Credit retirement offset Active 30 Mar 2025
EU CBAM Portal ?
How to set up: No API from the EU side — CBAM works as a structured XML export only. Setup in TerraCAP: (1) Mark tenants as CBAM-opted in their profile, (2) ensure those tenants enter production volume and process data for each product exported to EU, (3) TerraCAP calculates the Product Carbon Footprint per tonne and generates the XML file. The EU importer uses that XML to declare embedded emissions to their national authority.
XML export · manual trigger
 Generates product carbon footprint (PCF) data per tonne of goods exported to EU, formatted as the CBAM XML declaration file required by EU importers. Not a live API — triggered on demand. → PCF per product per opted tenant Manual export 15 Feb 2025
Cat 13 Auto-Aggregator
Internal event trigger · no external API
 This is an internal TerraCAP trigger, not an external connector. Whenever any tenant submits Scope 1 or Scope 2 data, this recalculates AMTZ's Cat 13 total automatically. No action needed — it runs silently in the background. → AMTZ Scope 3 Cat 13 (Own Inventory Row A) Active — real-time Real-time
