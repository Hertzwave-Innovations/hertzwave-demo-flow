Required Columns

  • scope_type — Scope 1, 2, or 3
  • category — e.g. natural_gas
  • value — Emission quantity
  • unit — m³, kWh, kg…
  • reporting_period — YYYY-MM-DD
  • emission_date — YYYY-MM-DD

Optional Columns

  • region_code — US, EU…
  • source — Source description
  • location — Location name
  • subcategory — Detail
  • supplier_id — Supplier ID
  • notes — Comments
