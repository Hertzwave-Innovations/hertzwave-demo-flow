Need the correct format?

Required Columns

  • category_type — Scope 1, Scope 2, Scope 3, Water, Waste
  • category — e.g. natural_gas, grid_electricity
  • value — Activity data quantity
  • unit — m³, kWh, kg, KL, MT…
  • reporting_period — YYYY-MM-DD
  • emission_date — YYYY-MM-DD

Optional Columns

  • region_code — US, EU…
  • source — Source description
  • location — Location name
  • subcategory — Detail
  • supplier_id — Supplier ID
  • notes — Comments
