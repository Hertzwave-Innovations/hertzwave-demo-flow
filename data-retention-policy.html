1. Overview

This Data Retention Policy outlines how long Hertzwave Innovations Pvt Ltd retains different types of data collected through the Hertzwave Carbon Accounting Platform (HWCAP). Our retention practices balance business needs, regulatory requirements, and user privacy rights.

🕐 Retention Principles

We retain data only as long as necessary for legitimate business purposes, regulatory compliance, or as permitted by law. Data is securely deleted when retention periods expire, except where legal obligations require longer retention.

Key Factors Influencing Retention:

  • Regulatory compliance requirements (BRSR, CBAM, CCTS)
  • Indian legal obligations (Companies Act 2013)
  • Business continuity and historical analysis needs
  • Data subject rights and privacy protection
  • Security and audit requirements

5. Data Deletion Process

🔄 Automated Deletion Workflows

HWCAP employs automated systems to ensure timely and secure deletion of data when retention periods expire.

5.1 Standard Deletion Procedure

1
Automated Identification

System identifies data reaching end of retention period through automated scanning processes.

2
Legal Hold Check

Verification that data is not subject to legal holds, regulatory investigations, or pending compliance requirements.

3
Pre-deletion Notification

For business-critical data, users receive 30-day advance notification before automated deletion.

4
Secure Deletion

Data is securely wiped using AWS-certified deletion methods following NIST 800-88 guidelines. AWS infrastructure ensures complete data destruction across all storage media and backup systems.

5
Deletion Certification

Certificate of destruction generated and maintained for audit purposes where required.

5.2 User-Initiated Deletion

Users can request immediate deletion of their data through:

  • Privacy settings in HWCAP dashboard
  • Formal request to [email protected]
  • Account closure procedures

Processing Time: User deletion requests processed within 30 days, subject to regulatory retention requirements.

5.3 Regulatory Exception Handling

Some data cannot be immediately deleted due to:

  • Ongoing regulatory investigations
  • Legal proceedings or disputes
  • Mandatory compliance retention periods
  • Tax audit requirements

Users are notified when regulatory exceptions prevent immediate deletion.

6. Security During Retention

🛡️ Data Security Measures

Throughout the retention period, all data is protected by enterprise-grade security measures to prevent unauthorized access, alteration, or disclosure.

  • Encryption: AES-256 encryption for data at rest and in transit via AWS KMS
  • Access Controls: Role-based access with multi-factor authentication via AWS IAM
  • Audit Trails: Comprehensive logging through AWS CloudTrail and application logs
  • Geographic Controls: Data stored in AWS Mumbai region (ap-south-1) for Indian data residency compliance
  • Backup Security: Automated encrypted backups via AWS RDS with 30-day rolling retention
  • Infrastructure Security: AWS SOC 2, ISO 27001, and PCI DSS compliant infrastructure
  • Cross-Region Redundancy: Disaster recovery setup across multiple AWS availability zones
  • Incident Response: 24/7 monitoring via AWS CloudWatch with immediate breach response procedures

AWS Infrastructure Compliance

HWCAP is hosted on Amazon Web Services (AWS) infrastructure, providing additional security and compliance benefits:

  • AWS Compliance Certifications: SOC 1/2/3, ISO 27001, PCI DSS Level 1, FedRAMP
  • Data Residency: All customer data stored in AWS Mumbai (ap-south-1) region
  • AWS Shared Responsibility Model: AWS manages infrastructure security, HWCAP manages application-level security
  • AWS Backup Services: Automated point-in-time recovery with 30-day retention per AWS policies
  • Secure Data Deletion: AWS-certified secure wiping following NIST 800-88 guidelines
  • Network Security: AWS VPC with private subnets and security groups

Regular Security Reviews

Data retention practices undergo quarterly security reviews to ensure:

  • Compliance with current security standards
  • Effectiveness of deletion procedures
  • Accuracy of retention period calculations
  • Proper handling of regulatory exceptions
